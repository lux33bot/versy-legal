Fonts, word list and software Versy is built with

Fonts

VersyDisplay, the heading face, is made from Tektur. Zilla Slab is the text face. The OR in This or That is drawn from Jost. All three are licensed under the SIL Open Font License, version 1.1 (scripts.sil.org/OFL), whose full text ships with the app’s source.

Word filter

The starting list of words the text filter refuses is adapted from the List of Dirty, Naughty, Obscene and Otherwise Bad Words by its contributors (github.com/LDNOOBW), licensed under Creative Commons Attribution 4.0 (creativecommons.org/licenses/by/4.0). Versy removed everyday words from it.

Software

Versy is built with open-source software released under the MIT License, including React, React Native, React Native Web, Expo and its modules, Expo Router, Reanimated, Worklets, Gesture Handler, Screens, Safe Area Context, SVG, Skia, FlashList, Keyboard Controller, Compressor, Nitro Modules, Masked View, Async Storage, URL Polyfill, aes-js and the Supabase JavaScript client.
